# 🗄️ HARIS Data Directory & Storage Schema

This directory stores biometric training data, pre-trained feature cascades, serialized LBPH facial recognition models, generated photo-embedded QR codes, and digital access badges.

---

## 📁 Directory Structure

```text
data/
├── haarcascade_frontalface_default.xml   # Pre-trained OpenCV Haar Cascade Face Detector
├── _mini_XCEPTION.106-0.65.hdf5          # Deep learning model weights (optional/extension)
│
├── classifiers/                          # Serialized LBPH facial recognition XML models
│   ├── <username>_classifier.xml         # Trained weights per registered user
│   └── ...
│
├── qrcodes/                              # Generated photo-QRs and verification badges
│   ├── <username>_qr.png                 # Level-H QR code with embedded user portrait
│   ├── <username>_badge.png              # 540x780 Cybernetic access ID pass
│   └── ...
│
└── <username>/                           # Individual user face dataset folders
    ├── 0<username>.jpg                   # Cropped face sample frame 0 (reference portrait)
    ├── 1<username>.jpg                   # Cropped face sample frame 1
    ├── ...
    └── 49<username>.jpg                  # Cropped face sample frame 49
```

---

## 📂 Subfolder Specifications

### 1. `data/<username>/` (Facial Image Datasets)
- Created automatically when executing **Dataset Capture** (`create_dataset.py` / GUI Step 1).
- Captures **50 normalized, cropped face frames** in standard `.jpg` format.
- `0<username>.jpg` serves as the primary reference portrait for QR codes, ID badges, and HUD overlays.

### 2. `data/classifiers/` (Trained Biometric Models)
- Created during **Classifier Training** (`create_classifier.py` / GUI Step 2).
- Contains serialized XML configuration files generated by `cv2.face.LBPHFaceRecognizer`.
- Contains histogram patterns, radii, grid neighborhood values, and trained weights for real-time inference.

### 3. `data/qrcodes/` (QR Tokens & Badges)
- Created during **Badge Generation** (`qr_generator.py` / GUI Step 3).
- **`*_qr.png`**: High-Error-Correction (`ERROR_CORRECT_H`, ~30% payload redundancy) QR code with a circular/rounded user portrait embedded in the center.
- **`*_badge.png`**: Cyberpunk-themed ID pass containing user metadata, verification status, reference photo, and scannable token.

### 4. `haarcascade_frontalface_default.xml`
- The default frontal face Haar feature-based cascade classifier used for rapid, low-latency face region detection during capture and verification.

---

## 🔒 Privacy & Data Retention Guidelines

1. **Local Storage**: All biometric facial images and model parameters remain local to your machine.
2. **Exclusion from Public Version Control**: If pushing to a public repository, you may wish to add `data/*` (except `haarcascade_frontalface_default.xml` and directory READMEs) to your `.gitignore` to protect personal biometric datasets.
